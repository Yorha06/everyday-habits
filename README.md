# Everyday Habits

Game sederhana untuk belajar bahasa Inggris kelas 6. Pelajari kebiasaan sehari-hari lewat soal yang beragam dan kumpulkan bintang!

## Mulai bermain

1. Jalankan `npm start`.
2. Buka http://localhost:8080 di browser.
3. Masukkan nama, lalu pilih **Ayo Mulai!** atau **Belajar Dulu**.

## Tentang permainan

- Satu sesi berisi 15 soal dengan tiga tingkat kesulitan: Pagi, Siang, dan Malam.
- Soal mencakup pilihan ganda, benar atau salah, melengkapi kata, menyusun kalimat, mencocokkan pasangan, menyimak, dan berbicara.
- Nilai tertinggi adalah 100. Skor terbaik tersimpan di browser.
- Soal menyimak dan contoh jawaban dibacakan oleh browser. Suara perempuan bahasa Inggris digunakan jika tersedia; jika tidak, browser memakai suara lain yang tersedia.
- Soal Speaking menggunakan mikrofon dan paling cocok dimainkan melalui Chrome atau Edge. Izinkan akses mikrofon saat diminta. Jika mikrofon tidak tersedia, permainan tetap bisa dilanjutkan dengan soal lain.
- Musik dan efek suara dapat mengikuti pengaturan suara perangkat.

## Berbagi permainan

Unggah folder ini ke layanan hosting web statis agar dapat dimainkan melalui internet.
